Snek Revolution by ShreyanCat

A custom snake arcade game made with Python and Pygame-ce. Created for Hack Club!
I wanted to make a snake game that differentiates itself from the base snake game.
So I added custom pixel sprites, speed scaling, hazards, and a timed golden apple power-up to the game
What's Included

• Start Menu + Game Over Screen : Pressing SPACE toggles between the menu and game. Pressing R restarts the game quickly
• Custom Pixel Sprites : You can use any custom .png files you want! I added coins for score and a snake head pixel sprite, but you can add any .png file you'd like
• Hazards + Special Food : Collect the coins for score, but watch out for those red hazard blocks! Eat the golden apple power-up before it disappears to get bonus points and speed!
• Multiplier System : Score points faster by eating coins without dying! Your multiplier resets to 1x if you hit a hazard
• Sound Effects : Eating coins and the game over jingle are implemented with .wav files

 Controls
• W / A / S / D or Arrow keys : Move the snake
• SPACE : Toggle game / menu
• R : Restart game after death
